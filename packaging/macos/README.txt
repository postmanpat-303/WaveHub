Wave Hub for macOS (Apple Silicon and Intel)
============================================

Wave Hub is free. Drag "Wave Hub" into Applications.

The first time, macOS may say it can't check the app, because it isn't notarised by
Apple yet. Right-click (or Control-click) Wave Hub, choose Open, then Open again.
After that it opens normally.

On macOS, Wave Hub can install BigWave Radio, ChipWave Studio and StreamWave.
