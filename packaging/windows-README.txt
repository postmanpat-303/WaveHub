Wave Hub - Windows x64
======================

Wave Hub is free. It installs, updates and opens the Wave apps
(BigWave Radio, ChipWave Studio and StreamWave).

Double-click WaveHub.exe to start it. Nothing else to install.
Windows may say it "protected your PC" because the file isn't code-signed
yet: click "More info", then "Run anyway".

Apps go into %LOCALAPPDATA%\WaveHub (no admin password needed).
