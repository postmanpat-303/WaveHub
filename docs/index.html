One-click install

Wave Hub picks the right file for your computer, downloads it with live progress and gets it ready to open.

🔄

Update all

It checks for new versions when it starts. One button brings every app up to date.

Uninstall and repair

Remove an app cleanly; your settings stay. If an app's files go missing, Repair puts them back.

Checksum-verified

Every download is checked against the release's SHA-256 list before it's installed. A bad download is never installed.

🚀

Keeps itself current

Wave Hub tells you when a new Wave Hub is out and links straight to the right download for your computer.

Finds what you have

Already installed an app yourself? Wave Hub spots it (Windows setups, Linux packages, Mac Applications) and looks after it too.

🏠

Your own folders

Apps install in your home folder on Linux, your Applications folder on Mac and your user folder on Windows. The Windows setup installs Wave Hub for everyone on the PC and asks for an administrator password; the portable zip and the other downloads need none.

Light or dark

Bright and friendly by default, with a dark theme one click away on the About page.

Safe by design

Wave Hub only does what it says, and you can read every line of it.

  • Official releases only: apps come straight from their own GitHub release pages, nowhere else.
  • Checked before installing: each file's SHA-256 checksum must match the release's list (SHA256SUMS.txt or SHA256SUMS).
  • Your settings stay: uninstalling an app leaves your settings alone, and apps you installed yourself are found, not moved.
  • No account, no tracking: Wave Hub only talks to GitHub to check versions and download files.
  • Open source: MIT licensed and written in Rust. Read the code.

Download Wave Hub

Free, for Windows, Linux and Mac. Every button downloads the newest version, so it's never out of date. Other files (portable zip, .deb, .rpm, Arch, Flatpak, ARM) are on the latest release page.

🪟WindowsYour computer

Windows 10 and later, 64-bit.

  • WaveHub-…-setup-x64.exe: the easy one, installs for everyone on the PC (asks for an administrator password)
  • WaveHub-…-windows-x64.zip: no install, unzip and run (no admin password)
Get the Windows setup

🐧LinuxYour computer

Regular PCs (x86_64) and 64-bit ARM, such as a Raspberry Pi 4 or 5.

  • .flatpak: any Linux with Flatpak · the x86_64 bundle
  • .AppImage: any Linux, make it runnable and go (64-bit ARM: aarch64 AppImage)
  • .deb Ubuntu, Debian, Mint · .rpm Fedora, openSUSE
  • .pkg.tar.zst Arch, CachyOS, Manjaro · .tar.gz anything else
Get the Linux AppImage (x86_64)

🍎MacYour computer

One app for Apple Silicon and Intel Macs.

  • WaveHub-…-macos-universal.dmg: open it, drag Wave Hub to Applications
  • WaveHub-…-macos-universal.zip: the same app, zipped
Get the Mac dmg

🛡 Wave Hub isn't code-signed yet. If Windows says it protected your PC, choose More info → Run anyway. On a Mac, the first time, right-click Wave Hub and choose Open.
